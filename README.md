# dice_game

Same-table Pig. Two warriors, two dice, one device.

## Rules

- Roll both dice as often as you like. The total is added to the current round.
- A 1 on either die loses the round and passes the turn.
- Double 6 wipes that player's banked score and passes the turn.
- Hold banks the round, then the other warrior plays.
- First to the winning score wins. Set it before New game (default 100, minimum 20).

Space rolls, H holds, N starts a new game.
